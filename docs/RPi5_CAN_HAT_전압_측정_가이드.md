# RPi5 CAN HAT 전압 측정 가이드

작성일: 2026-11-16. 대상: Seengreat RS485 Dual CAN I / Raspberry Pi 5.

**SSH 연결 없이 측정하고, 아래 기록표를 채워 나중에 전달하면 된다.**
현재 필요한 것은 CAN 선의 전압보다 HAT 내부 논리 전원과 RESET 상태 확인이다.
외부 CAN 장치를 연결하지 않아도 이번 측정은 가능하다.

## 1. 현재까지 확인한 내용

- HAT는 40핀으로 장착돼 있으며, 사용자가 로직 선택 3.3V와 기존 DIP 설정 유지를 확인했다.
- 2026-11-16 새 커널 `6.18.62-v8-16k+`에서도 MCP2515 초기화가 시간 초과로 실패했다.
- 필요한 CAN·SPI 커널 설정과 CAN0 장치 트리 설정은 존재한다.
- 이전 하드웨어 SPI 및 GPIO 직접 제어 시험에서도 유효한 칩 응답을 확보하지 못했다.
- 2026-11-16 14:50 사용자 측정: 헤더 5V는 **5.2V**, SW3 V-IO는 **3.3V**였다.
- 후속 사용자 보고서에서 U4 VDD·RESET#는 각각 3.3V로 측정됐다. U5 값은 미확인이다.
- 내부 3V3 입력은 미측정이며, HAT 불량으로 확정한 상태가 아니다.

상세 이력: [40핀 종합 점검 결과](RPi5_CAN_40핀_종합_점검_결과.md).

## 2. 측정 장소로 가져갈 것

- RPi, CAN HAT, 평소 사용하는 RPi 전원 공급기와 케이블.
- 멀티미터와 프로브. 가능하면 절연된 미세 프로브 또는 작은 측정용 클립.
- 이 문서의 저장본 또는 인쇄본.

RPi는 정상 종료한 다음 전원을 분리해 이동한다. 측정 장소에서는 기존과 같은 40핀 장착 상태로 전원을 켠다.
네트워크 연결과 STM32 연결은 필수가 아니다. 별도의 7선 우회 배선은 필요하지 않다.

## 3. 멀티미터 설정과 기준 GND

1. 검은 리드는 **COM**, 빨간 리드는 **V/Ω** 단자에 꽂는다.
2. **DC 전압(V⎓)**, 자동 범위 또는 20V 범위로 설정한다.
3. 검은 프로브의 기준은 HAT 왼쪽 노란색 12핀 헤더에 인쇄된 **GND**다.
4. 빨간 프로브만 측정점으로 옮긴다. 인접 핀 두 개에 동시에 닿지 않도록 한다.

전원이 켜진 상태에서는 저항·도통·전류 측정을 하지 않는다.
검은 프로브를 고정할 클립은 전원을 끈 상태에서 연결한다.
좁은 측정점은 위치를 확실히 식별하고 안전하게 접촉할 수 있을 때만 측정한다.

이 가이드의 전압은 모두 **논리측 GND 기준**이다.
CAN0 단자의 `G`는 이 기준점 대신 사용하지 않는다.

## 4. 순서대로 측정하기

### 4-1. 먼저 5V 입력 측정

HAT 왼쪽 노란색 12핀 헤더에서 실크 인쇄를 확인한다.
`5V`와 `GND`는 서로 이웃한 핀이며, `5V` 쪽이 전원 입력 단자에 가까운 끝이다.
보드의 방향이 달라질 수 있으므로 사진의 위아래보다 **실물의 글자**로 찾는다.

- 검은 프로브: 이 헤더의 `GND`.
- 빨간 프로브: 같은 헤더의 `5V`.
- 기대: 약 **5V**.

0V이거나 5V보다 뚜렷하게 낮으면 값을 기록하고 후속 측정을 멈춘다.
프로브가 실제 핀 금속에 닿았는지 먼저 확인한다.
이 경우 전원 공급·40핀 접촉·HAT 전원 경로를 우선 확인해야 하며, 바로 부품 불량으로 판단하지 않는다.

### 4-2. 내부 논리 전원 V-IO 측정

**5V 전원 입력과 3.3V/5V 로직 선택은 별개다. 로직 선택은 계속 3.3V로 유지한다.**

제조사 V1.2 회로도의 로직 선택 스위치 `SW3`는 전기적 단자 1=5V, 2=V-IO, 3=3V3다.
`V-IO`가 MCP2515의 논리 전원이다.

- 검은 프로브: 앞서 사용한 노란색 헤더의 `GND`.
- 빨간 프로브: `SW3`의 **가운데 전기적 단자(2번, V-IO)**.
- 기대: 3.3V 선택 상태에서 약 **3.3V**.

스위치의 금속 고정 탭은 전기적 단자와 다르다.
실물 리비전과 단자 위치를 회로도에 대조하기 어렵거나 프로브가 너무 굵으면 **미측정**으로 남긴다.
전원을 켠 채 스위치를 움직이거나, 옆 단자와 연결되도록 프로브를 대지 않는다.

측정에 익숙한 사람의 도움을 받을 수 있다면, `SW3`의 3V3 입력 단자도 같은 GND 기준으로 측정한다.
내부 3V3 입력과 V-IO 출력을 비교하면 전원 생성 문제와 스위치 접점 문제를 구분하는 데 도움이 된다.
RPi 40핀의 3.3V 핀 측정만으로 HAT 내부 V-IO가 정상이라고 판단하지 않는다.

### 4-3. RESET 측정 — 미세 측정이 가능할 때만

이 단계는 보드 리비전·부품 번호·핀 1 방향을 확인할 수 있는 사람과 진행한다.
**18핀 MCP2515의 V1.2 회로도 기준**으로 CAN0는 `U4`, CAN1은 `U5`이며,
RESET#는 17번, VDD는 18번, VSS는 9번이다.
RESET#는 각 10kΩ 저항 `R3`/`R4`를 통해 V-IO로 풀업된다.

- 검은 프로브: 노란색 헤더의 `GND`.
- 빨간 프로브: 해당 칩의 RESET# 또는 회로도로 확인한 RESET 신호 측 저항 패드.
- 기대: 부팅 후 안정 상태에서 V-IO와 비슷한 전압, 현재 설정에서는 약 **3.3V**.

핀 번호는 보드 사진의 좌우로 추측하지 않는다. RESET# 옆의 VDD 등 다른 핀을 동시에 건드리지 않는다.
안전한 측정이 어렵다면 RESET 항목은 비워 두고, 5V와 V-IO 결과부터 전달한다.

DC 전압이 정상이어도 SPI 통신·발진자·리셋 시퀀스까지 정상임을 증명하지는 않는다.
일반 멀티미터로 16MHz 발진이나 SPI 파형의 정상 여부를 판정하지 않는다.

측정점의 회로 연결은 [제조사 V1.2 회로도][schematic]를 기준으로 한다.
보드의 스위치·헤더 설명은 [제조사 안내](https://seengreat.com/wiki/83/rs485-dual-can-i)를 참고한다.

## 6. 측정 후 판단 방향

| 결과 | 다음 확인 |
| --- | --- |
| 헤더 5V가 없거나 크게 낮음 | 전원 공급기·케이블·40핀 접촉·HAT 전원 경로 |
| 5V 정상, 내부 3V3 입력이 낮음 | HAT 내부 3.3V 생성 회로 또는 해당 전원망 부하 |
| 내부 3V3 입력 정상, V-IO가 낮음 | SW3 접점·납땜·V-IO 경로 또는 해당 전원망 부하 |
| V-IO 정상, RESET#가 LOW | RESET 풀업·배선·접촉 및 해당 신호 경로 |
| V-IO가 약 5V | 전원을 끄고 로직 선택 및 측정점 확인. RPi에 연결한 상태로 계속 시험하지 않음 |
| 5V·V-IO·RESET#가 모두 예상 수준 | CS·SCLK·SI/SO 전달, 발진자 또는 정상 장비와 교차 시험 |

이 표는 원인 후보를 좁히기 위한 것이며, 단일 전압값으로 특정 부품 불량을 확정하지 않는다.
PWR LED 점등만으로 논리측 전원 정상 여부를 대신 판단하지 않는다.

측정 후에는 프로브를 치우고 RPi를 정상 종료한다. 다음 SSH 재시험은 측정 결과를 확인한 뒤 진행한다.

## 7. 2026-11-16 측정 결과 해석과 다음 점검

사용자가 기록한 5.2V 입력과 3.3V V-IO에서는 뚜렷한 전원 부재가 보이지 않는다.
SW3 출력이 3.3V이므로, 측정 당시 스위치 출력까지 전압이 도달한 것은 확인됐다.
다만 검은 프로브 위치에는 확인용 문구가 남아 있고 멀티미터 모드·범위는 미기록이다.
아래 해석은 안내한 DC 전압 모드와 논리측 GND를 사용했다는 전제다.

이 결과는 MCP2515 칩 핀의 전원·RESET, 순간적인 전압 강하 또는 SPI 신호 전달까지 증명하지 않는다.
같은 속도·모드 변경 시험을 반복하기보다 다음 중 가능한 방법으로 원인을 구분한다.

### 7-1. 가장 빠른 구분: 정상 장비와 교차 시험

- 정상 동작을 확인한 동일 HAT를 현재 RPi에 연결한다.
- 또는 현재 HAT를 정상 동작이 확인된 다른 RPi와 호환 설정에서 시험한다.

교체는 정상 종료·전원 분리 후 수행한다.
정상 HAT만 현재 RPi에서 동작한다면 현재 HAT의 회로·접점을 우선 확인한다.
현재 HAT가 다른 RPi에서 동작한다면 현재 RPi의 핀·접촉·설정 경로를 우선 확인한다.
이 비교도 사용한 설정과 연결 조건을 함께 기록한다.

### 7-2. 멀티미터로 추가 확인할 경우

다음 현장 측정에서는 SW3 출력 다음 구간인 **U4/U5 VDD(18번)**와
**RESET#(17번)**를 논리측 GND 기준으로 확인한다. 현재 선택에서 기대값은 각각 약 3.3V다.
칩 다리에 안전하게 접근하기 어려우면 측정 경험이 있는 사람에게 요청한다.

전원 분리 상태의 도통 확인도 가능하다.
RPi를 정상 종료한 뒤 전원·USB·외부 CAN 연결을 모두 분리하고 HAT를 RPi에서 떼어 낸다.
보드에 전원이 남아 있지 않은 상태에서 저항·도통 모드를 사용한다.
프로브를 서로 맞댔을 때의 리드 저항과 비교하고, 부저 유무와 저항값을 함께 기록한다.

| HAT의 40핀 커넥터 물리 번호 | CAN0 U4의 연결 핀 |
| --- | --- |
| 19, MOSI | 14, SI |
| 21, MISO | 15, SO |
| 23, SCLK | 13, SCK |
| 24, CE0 / 26, CE1 | 16, CS# — DIP에서 선택한 경로 하나 |

위 경로는 현재 DIP 설정과 제조사 V1.2 회로도 기준이다.
전원을 분리한 HAT의 커넥터에서 측정하며, RPi 자체의 핀과 혼동하지 않는다.
실물 리비전·칩 핀 1 방향을 먼저 대조한다.
도통이 없으면 해당 경로의 DIP 접점·납땜·배선을 확인하고,
도통이 있어도 실제 SPI 파형이 정상이라는 뜻으로 해석하지 않는다.

### 7-3. 전원·RESET·도통이 정상일 경우

로직 애널라이저로 U4에서 CS·SCLK·SI·SO를 함께 관측해 명령 전달과 응답을 확인한다.
신호를 캡처하려면 SPI 전송을 발생시키는 원격 시험과 측정을 같은 시간에 진행해야 한다.
이 단계는 전원을 켠 상태에서 파형을 보는 시험이며 앞의 무전원 도통 측정과 구분한다.
발진자의 16MHz 동작과 신호 전압·품질 확인에는 적절한 오실로스코프 측정이 필요하다.
이 장비가 없다면 교차 시험 또는 제조사에 측정 결과를 전달하는 쪽으로 진행한다.

## 8. 후속 CS0 전환 시험 후 현재 상태

전압 측정 이후 사용자가 CAN0 DIP를 **P11 OFF·P10 ON**으로 변경했다.
원격에서 부팅 설정도 `spi0-0`으로 수정하고 재부팅해 적용을 확인했다.
CS0에서도 초기화가 실패했고, SPI 100kHz·500kHz 직접 읽기 총 6회에서 모두 `00 00`을 받았다.
현재도 CAN 인터페이스는 없으며 상세 결과는 [종합 점검 기록](RPi5_CAN_40핀_종합_점검_결과.md)에 있다.

CS0 전환 시험 시 CAN0 CS 경로는 **물리 24번(CE0)**였다.
MOSI·MISO·SCLK 경로와 U4의 CS# 핀 번호는 동일하다.
초기 도통 표의 물리 26번은 P11 ON·P10 OFF일 때의 경로다.
측정 때는 실제 DIP 상태에 해당하는 경로를 선택한다. 로직 선택은 3.3V를 유지한다.

## 9. 후속 멀티미터 보고서에 따른 우선순위 변경

사용자 보고서에서 U4 VDD·RESET# 각 3.3V, CAN0 SPI 경로 도통과
MOSI·MISO·SCLK 사이 1MΩ 이상이 추가로 보고됐다.
HAT를 제거한 상태에서도 GPIO8·11·21의 출력 LOW가 약 1V였고,
GPIO21은 `gpioset`이 출력을 요청해 유지하는 중에도 같은 전압이었다고 한다.
이는 RPi GPIO의 정적 출력·측정 환경·독립 OS 비교를 먼저 확인할 근거다.
이 결과만으로 RPi 또는 HAT 고장을 확정하지 않는다.

이후 보고서에서는 GPIO 독립 시험을 위해 SPI와 CAN overlay를 비활성화했다고 한다.
8절은 이전 CAN 시험 상태이며 현재 RPi 실행 상태를 보증하지 않는다.
새 관측의 범위와 다음 최소 검증은 [GPIO 추가 측정 요약](RPi5_CAN_GPIO_추가_측정_요약.md)에 정리했다.
